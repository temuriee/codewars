# ამოცანა

Your task is to make two functions ( max and min, or maximum and minimum, etc., depending on the language ) that receive a list of integers as input, and return the largest and lowest number in that list, respectively. Each function returns one number.

Examples (Input -> Output)

- [4,6,2,1,9,63,-134,566] -> max = 566, min = -134
- [-52, 56, 30, 29, -54, 0, -110] -> min = -110, max = 56
- [42, 54, 65, 87, 0] -> min = 0, max = 87
- [5] -> min = 5, max = 5

---

# ამოხსნა

```javascript
export const min = (list: number[]): number => {
  return Math.min(...list);
};

export const max = (list: number[]): number => {
  return Math.max(...list);
};
```

# How It Works

we use built in functions called Math.min() and Math.max() Math.min() returns smallest number and Math.max() Returns largest one inside we give them ...list and we need spread operator because this functions expect numbers not array thats why we need to take numbers out from array one by one and thats why we use spread operator
