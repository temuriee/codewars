# ამოცანა

---

### ✅ Simple version:

```javascript
function evenOrOdd(number) {
  if (number % 2 === 0) {
    return "Even";
  } else {
    return "Odd";
  }
}
```

---

---

### 💡 Example:

```javascript
evenOrOdd(4); // "Even"
evenOrOdd(7); // "Odd"
```

# ამოხსნა

```javascript
function evenOrOdd(number) {
  return number % 2 === 0 ? "Even" : "Odd";
}
```
