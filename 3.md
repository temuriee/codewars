# ამოცანა

Here’s the clean and correct way to write it 👇

---

### ✅ Using `if / else` (best approach)

```javascript
function bmi(weight, height) {
  const value = weight / height ** 2;

  if (value <= 18.5) {
    return "Underweight";
  } else if (value <= 25.0) {
    return "Normal";
  } else if (value <= 30.0) {
    return "Overweight";
  } else {
    return "Obese";
  }
}
```

---

### 💡 Example:

```javascript
bmi(70, 1.75); // "Normal"
```

---

### ⚡ Short version (one-liner):

```javascript
function bmi(weight, height) {
  const v = weight / height ** 2;
  return v <= 18.5
    ? "Underweight"
    : v <= 25
      ? "Normal"
      : v <= 30
        ? "Overweight"
        : "Obese";
}
```

# ამოხნსა

# 1. else if statement

```javascript
function bmi(weight, height) {
  if (weight / height ** 2 <= 18.5) {
    return "Underweight";
  } else if (weight / height ** 2 <= 25.0) {
    return "Normal";
  } else if (weight / height ** 2 <= 30.0) {
    return "Overweight";
  } else {
    return "Obese";
  }
}
```

# 2. switch statment

```javascript
function bmi(weight, height) {
  switch (true) {
    case weight / height ** 2 <= 18.5:
      return "Underweight";
    case weight / height ** 2 <= 25.0:
      return "Normal";
    case weight / height ** 2 <= 30.0:
      return "Overweight";
    default:
      return "Obese";
  }
}
```
