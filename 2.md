# ამოცანა

This is a classic beginner problem — you just need to check the **first letter** of the name.

---

### ✅ JavaScript solution:

```javascript
function areYouPlayingBanjo(name) {
  return name[0].toLowerCase() === "r"
    ? name + " plays banjo"
    : name + " does not play banjo";
}
```

---

### 💡 How it works:

- `name[0]` → gets the first letter
- `.toLowerCase()` → makes it lowercase (so "R" and "r" both work)
- Then just return the correct string

---

### ✅ Example:

```javascript
areYouPlayingBanjo("Rick"); // "Rick plays banjo"
areYouPlayingBanjo("adam"); // "adam does not play banjo"
```

# ამოხსნა

```javascript
function areYouPlayingBanjo(name) {
  if (name[0].toLowerCase() === "r") {
    return name + " plays banjo";
  } else {
    return name + " does not play banjo";
  }
}
```
