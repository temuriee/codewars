# ამოცანა

You just need to square each number and add them up. Here’s a clean full-stack-dev style solution (simple, readable, efficient):

### JavaScript solution:

```javascript
function squareSum(numbers) {
  return numbers.reduce((sum, num) => sum + num * num, 0);
}
```

### How it works:

- `reduce` loops through the array
- `num * num` squares each number
- `sum + ...` accumulates the total
- `0` is the starting value

### Example:

```javascript
squareSum([1, 2, 2]); // 9
```

---

### Alternative (more beginner-friendly):

```javascript
function squareSum(numbers) {
  let sum = 0;
  for (let i = 0; i < numbers.length; i++) {
    sum += numbers[i] * numbers[i];
  }
  return sum;
}
```
